01 개발 배경 및 문제 정의
과제 개요

모바일 로보틱스 수업에서는 실제 로봇 플랫폼을 대상으로 두 가지 자율 주행 태스크를 구현하고 검증하는 것을 목표로 하였다. 전역 경로 계획기(global planner)나 Navigation2 스택 없이, 순수 피드백 제어만으로 목표 포즈에 도달하는 것이 핵심 제약 조건이었다.

제약: ROS 2 Nav2 미사용. /odom 과 /cmd_vel 토픽만으로 제어 루프 완성. 목표 좌표는 런치 파라미터로 주입, 노드 내 하드코딩 금지.
Task 2 — 자율 주차

단일 목표 포즈 (x, y, θ) 로 로봇을 정밀하게 이동시키고, 위치 오차와 헤딩 오차가 모두 임계값 이하일 때 정지한다. 실제 주차 시나리오에서는 최종 방향 정렬이 필수적이므로 beta 항을 포함한 3-gain 제어기를 적용하였다.

Task 3 — 웨이포인트 내비게이션

3개의 중간 웨이포인트를 순서대로 경유한 후 원점으로 복귀한다. 각 구간 전환 시 다음 구간 방향으로 사전 정렬(ROTATE 단계)을 수행하여 경로 이탈을 최소화한다. 마지막 구간(원점 복귀)에서는 LiDAR로 전방 장애물을 감지하여 자동 회피한다.

03 핵심 구현 상세
극좌표 피드백 제어기

로봇과 목표 포즈 사이의 오차를 극좌표 3변수(rho, alpha, beta)로 분해하고, 각 변수에 비례 이득을 곱해 속도 명령을 생성한다.

# 오차 분해
rho   = sqrt(dx**2 + dy**2)          # 목표까지의 유클리드 거리
alpha = atan2(dy, dx) - theta_curr    # 목표 방향 오차
beta  = -(theta_curr + alpha)          # 최종 헤딩 정렬 오차

# 속도 명령 생성
v     = k_rho   * rho
omega = k_alpha * alpha + k_beta * beta

# 속도 제한 적용
v     = max(v_min, min(v_max, v))
omega = max(-omega_max, min(omega_max, omega))
설계 의도: 마지막 원점 복귀 구간에서는 beta 항을 제거하고 alpha 항만 사용한다. 원점에서 최종 헤딩 정렬을 강제하면 제자리 회전 후 정지하지 않고 진동할 수 있기 때문이다.
이득값 (Waypoint)값 (Parking)역할
k_rho0.20.2거리에 비례하는 전진 속도
k_alpha1.01.0목표 방향 오차 보정 각속도
k_beta-0.3-0.6최종 헤딩 정렬 (주차는 더 강하게 적용)

웨이포인트 상태 머신

각 웨이포인트 전환 시 제자리 회전 단계(ROTATE)를 삽입하여 다음 구간 방향으로 사전 정렬한다. 급격한 방향 전환으로 인한 경로 이탈을 방지하기 위한 설계다.

MOVE → ROTATE → MOVE → ROTATE → ... → STOP
충돌 감지 시 (idx == 3 한정): AVOID_ROTATE → AVOID_FORWARD → MOVE (재개)
1
MOVE: 극좌표 제어기로 현재 웨이포인트를 향해 주행. rho < 0.1 m 도달 시 전환.
2
ROTATE: 다음 웨이포인트 방향(atan2)으로 제자리 회전. 헤딩 오차 15도 이하 시 인덱스 증가 후 MOVE 복귀.
3
STOP: 마지막 원점(idx == 3) 도달 시 zero twist 발행 후 종료.
LiDAR 기반 충돌 회피

/scan 콜백에서 전방 60도 섹터(330°–360° ∪ 0°–30°)의 유효 거리 값을 수집하고, 최솟값이 0.5 m 미만이면 즉시 회피 시퀀스를 삽입한다. 회피는 마지막 구간(idx == 3)에서만 활성화되어 중간 구간의 불필요한 인터럽트를 방지한다. 

for i, dist in enumerate(scan.ranges):
    angle = scan.angle_min + i * scan.angle_increment
    if scan.range_min < dist < scan.range_max:
        # 전방 ±30도 필터 (라디안 기준)
        if (angle >= 5.76 and angle <= 6.28) or (angle <= 0.523):
            front_ranges.append(dist)

if front_ranges and min(front_ranges) < 0.5:
    self.phase = "AVOID_ROTATE"    # 왼쪽 1.5 s 회전 → 직진 5.0 s

감지 거리 임계값0.5 m
회피 회전 시간1.5 s (좌회전 0.8 rad/s)
회피 직진 시간5.0 s (0.12 m/s)
활성화 구간idx == 3 (원점 복귀 구간 한정)
한계: 시간 기반 회피(time-based open-loop)이므로 장애물의 크기나 위치에 따라 회피 후 경로가 크게 벗어날 수 있다. 회피 완료 후 원래 목표 방향으로의 복귀는 극좌표 제어기가 자연스럽게 처리한다.
런치 파라미터 설계

목표 좌표를 노드 내부에 하드코딩하지 않고 런치 파일의 parameters 필드로 주입한다. 로봇 환경 변경 시 런치 파일만 수정하면 된다.
